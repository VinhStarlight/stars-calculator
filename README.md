# Star's Calculator

Star's Calculator is a lightweight in-game calculator for Minecraft. It lets you quickly work out item counts, crafting totals, and other calculations without leaving the game.

## Features

- Basic arithmetic
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Decimal support
- Stack mode for converting item counts into stacks
  - 64
  - 16
  - Off
- Keyboard-driven interface
- Lightweight with no unnecessary features

## Requirements

- Minecraft 26.2
- Fabric Loader
- Fabric API

## Planned Features
