# Star's Calculator

A simple keyboard-driven calculator for Minecraft, made with Fabric.

## Features

* Basic arithmetic
* Parentheses and decimals
* `x` and `*` multiplication
* Minecraft stack calculations
* Simple in-game GUI
* Keyboard-first input

## Controls

| Key         | Action            |
| ----------- | ----------------- |
| `C`         | Open calculator   |
| `0-9`       | Numbers           |
| `+`         | Addition          |
| `-`         | Subtraction       |
| `/`         | Division          |
| `x`         | Multiplication    |
| `Shift + 8` | `*`               |
| `Backspace` | Delete            |
| `Enter`     | Calculate         |
| `Tab`       | Switch stack mode |

## Stack Mode

Press `Tab` to switch between 64-stack, 16-stack, and disabled modes.

For example:

```text
130
2 stacks + 2 items
```

## Requirements

* Minecraft 26.3
* Fabric Loader
* Fabric API
* Java 25+
